Leopoldo Romano - Portfolio

Live site:
https://leopoldoromano7-ops.github.io/Portfolio/

Descrizione
Portfolio personale di Leopoldo Romano, junior full stack developer con background in grafica e comunicazione visiva.
Il progetto presenta profilo, competenze, percorso, progetti e contatti in una veste visuale cyberpunk/HUD personalizzata.

Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- AOS
- Swiper
- Glightbox

Contenuti principali
- Hero orientata a candidatura junior full stack
- Sezione competenze con hub interattivo e modal per ramo
- Sezione percorso con due rotte principali
- Sezione progetti con focus su contesto, ruolo e contributo
- Sezione contatti con call to action diretta

Deploy
Il sito e pubblicato tramite GitHub Pages.

Note
Questo progetto nasce da una base BootstrapMade "iPortfolio", poi modificata in modo sostanziale per struttura, contenuti, stile e interazioni.
Template originale:
https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/
